操作说明 · 分类管理

  • 重命名：点分类名，改完按回车或点其他地方保存
  • 合并：点 ⇄ 选目标分类，当前分类下所有条目会并入目标分类
  • 删除：点 🗑 会连同该分类下所有条目一起删除，不可撤销
  • 排序：拖动左侧 ⠿ 手柄调整顺序
  • 写入文件：wiki-data.json
自动读取 GitHub Releases，手动编辑作为覆盖层

操作说明 · 下载源管理

  • 自动条目（自动）：来自 GitHub Releases，改了字段后会变成「已覆盖」并写入 JSON
  • 已覆盖（已覆盖）：自动条目的字段被手动修改
  • 独立资源（独立）：手动添加，不来自 Releases
  • 隐藏：自动条目通过「隐藏」从下载站移除（不会删除 Release）
  • 删除：独立资源可以真删除；自动条目只能隐藏
  • 写入文件：download-data.json
管理首页工具箱的卡片：图标、名称、描述、分类、链接、废弃状态

操作说明 · 工具管理

  • 修改：点卡片右侧 ✏️ 修改任意字段
  • 废弃/启用：编辑时勾选「已废弃」，卡片会从「可用工具」移到「已废弃」栏
  • 禁用点击：卡片还在，但点击抖动提示，不跳转
  • 隐藏：勾选「隐藏」后，首页完全不显示（适合临时下线）
  • 排序：拖动 ⠿ 手柄调整顺序
  • 删除：点 🗑（保存前刷新页面即可还原）
  • 写入文件：tools-data.json

操作说明 · 福利目标

  • 添加目标：点左上「＋ 添加目标」新增一行
  • 编辑：直接点名称/数值输入框修改
  • 删除：点右侧 🗑
  • 排序：拖动 ⠿ 手柄调整顺序
  • 保存：点「💾 保存目标到 GitHub」写入仓库
  • 写入文件：welfare-targets.json · 助力总数来自 Supabase welfare_boost 的 sum(amount)
商品来自 GitHub · welfare-shop.json

操作说明 · 商店管理

  • 添加商品：点左上「＋ 添加商品」追加一行
  • 编辑：直接改卡片里的输入框
  • 下架：取消勾选「上架」
  • 删除：点右侧 🗑
  • 排序：拖动 ⠿ 手柄调整顺序
  • 保存：改完点顶栏「💾 保存并推送」写入仓库
  • 写入文件：welfare-shop.json
