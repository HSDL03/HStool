操作说明 · 分类管理

  • 重命名：点分类名，改完按回车或点其他地方保存
  • 合并：点 ⇄ 选目标分类，当前分类下所有条目会并入目标分类
  • 删除：点 🗑 会连同该分类下所有条目一起删除，不可撤销
  • 排序：拖动左侧 ⠿ 手柄调整顺序
  • 写入文件：wiki-data.json
自动读取 GitHub Releases，手动编辑作为覆盖层

操作说明 · 下载源管理

  • 自动条目（自动）：来自 GitHub Releases，改了字段后会变成「已覆盖」并写入 JSON
  • 已覆盖（已覆盖）：自动条目的字段被手动修改
  • 独立资源（独立）：手动添加，不来自 Releases
  • 隐藏：自动条目通过「隐藏」从下载站移除（不会删除 Release）
  • 删除：独立资源可以真删除；自动条目只能隐藏
  • 写入文件：download-data.json
管理首页工具箱的卡片

操作说明 · 工具管理

  • 搜索：输入关键字实时过滤（名称 / 描述 / 标签 / ID / 链接）
  • 数据库分类：每个工具可标记「需要访问数据库」或「不需要访问数据库」
  • 标签分类：编辑时填的「分类标签」会出现在上方标签下拉框中，选择后只显示该标签下的工具
  • 状态筛选：可用 / 已废弃 / 隐藏
  • 修改：点卡片右侧 ✏️ 修改任意字段
  • 禁用点击：卡片还在，但点击抖动提示，不跳转
  • 排序：拖动 ⠿ 手柄调整顺序
  • 写入文件：tools-data.json
公告来自 GitHub · announcement.json

操作说明 · 公告管理

  • 折叠 / 展开：点公告标题栏可折叠或展开该条公告的编辑区域
  • 批量操作：上方「展开全部 / 折叠全部」一键切换
  • 分类：可归入更新日志 / 维护通知 / 活动公告 / 重要警告
  • 类型：info（蓝） / success（绿） / warn（黄） / danger（红）
  • 启用：取消勾选「启用」相当于暂时隐藏
  • 链接：可空；填了会在公告底部显示跳转按钮
  • 排序：拖动 ⠿ 手柄调整顺序
  • 写入文件：announcement.json
