💡 使用说明：所有效果药水都要先做 粗制的药水（水瓶 + 下界疣）。把糖、闪烁的西瓜之类直接丢进水瓶只会得到 平凡的药水，没有效果；浓稠的药水（水瓶 + 萤石粉）和普通的药水都酿不出东西。 唯一的例外是 虚弱：发酵蜘蛛眼直接加在水瓶上（Java 版加在粗制的药水上无效）。 腐化只收录确认的几条：迅捷/跳跃 → 缓慢、治疗/中毒 → 伤害、夜视 → 隐身。 延长时间是原版固定值（3:00 → 8:00、1:30 → 4:00、0:45 → 1:30），不是统一翻倍；标「—」的项目原版没有该变体或时长说法不一。
数据基于 Java 版 1.20+，基岩版可能有差异。
